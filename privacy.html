Kebijakan Privasi

Terakhir diperbarui: 21 Oktober 2026

Selamat datang di Dapur Pintar ("kami", "aplikasi"). Kami berkomitmen penuh untuk melindungi privasi serta keamanan data pribadi Anda. Kebijakan Privasi ini menjelaskan bagaimana informasi Anda dikumpulkan, digunakan, disimpan, dan dilindungi saat menggunakan aplikasi Dapur Pintar di perangkat seluler maupun web.

database

1. Informasi yang Kami Simpan Secara Lokal

Dapur Pintar dirancang dengan prinsip local-first. Data berikut disimpan langsung di memori perangkat Anda menggunakan Capacitor Native Preferences (atau LocalStorage pada peramban web):

  • Daftar Stok Bahan: Catatan inventaris kulkas dan bumbu dapur (nama bahan, jumlah, satuan, tanggal simpan, dan status kesegaran).
  • Riwayat Memasak & Belanja: Log masakan yang telah diolah dan daftar belanja bahan makanan.
  • Pengaturan Pengguna: Nama panggilan profil dan preferensi tampilan.

Kami tidak mengumpulkan nama lengkap asli, nomor telepon, kata sandi, maupun data perbankan pengguna.

photo_camera

2. Izin Kamera & Pemrosesan Citra (Scan)

Aplikasi memerlukan izin akses kamera fisik perangkat untuk fungsi berikut:

  • Pemindaian Kulkas / Struk: Foto yang Anda ambil hanya diubah menjadi format biner sementara untuk dianalisis oleh antarmuka pemrograman aplikasi kecerdasan buatan (Google Gemini API) guna mengidentifikasi nama bahan dan estimasi kedaluwarsa.
  • Deteksi Barcode: Pemindaian kode garis kemasan bahan makanan secara lokal untuk mengisi nama produk secara instan.

🔒 Jaminan Keamanan: Foto Anda tidak pernah disimpan di galeri publik server kami, tidak dijual ke pihak ketiga, dan tidak digunakan untuk keperluan periklanan.

cloud_sync

3. Sinkronisasi Cloud Opsional

Jika Anda mengaktifkan sinkronisasi awan (Cloud Sync via Firebase Firestore), data inventaris stok dikaitkan dengan ID perangkat anonim acak (usr_xxxx) agar Anda dapat mencadangkan atau berbagi daftar belanja dengan anggota keluarga. Anda dapat memutuskan tautan atau mengosongkan data kapan pun.

delete_forever

4. Hak Penghapusan Data (Data Deletion)

Sesuai dengan ketentuan Google Play Store dan regulasi perlindungan data pribadi, pengguna memiliki hak penuh untuk menghapus seluruh data yang tersimpan.

Cara Menghapus Seluruh Data:

  1. Buka menu Pengaturan (ikon gerigi) di pojok kanan atas aplikasi Dapur Pintar.
  2. Gulir ke bawah hingga bagian "Hapus Semua Data".
  3. Tekan tombol tersebut dan lakukan konfirmasi ganda. Seluruh riwayat inventaris lokal maupun cloud akan dibersihkan seketika.
